## Defects fixed during this pass

1. The old code challenge only searched for case-sensitive words.
2. Several code challenge requirements were impossible or unrelated to valid
   Java.
3. Passing code advanced immediately, hiding the result.
4. Interaction-first sequencing jumped to a late quiz instead of the first
   code task.
5. Five migrated stories ended in truncated sentences.
6. Corrupt local progress could break the lesson.
7. Browser storage failure could throw during progress save.
8. The timed boss could finish more than once.
9. `concept-details.json` was missing its final closing structure.
10. The concept page loaded Tailwind's development runtime in production.
11. The company redirect accepted an unbounded query value.
12. Static validation did not parse ordinary JSON or check basic HTML
    integrity.

## Important limits

- The Java debugger is a fast, private structural and lesson-requirement
  checker. It does not claim to be a Java compiler or execute untrusted code.
- A credentialed Cognito session, logout, cross-device DynamoDB sync, and
  two-account isolation still require a controlled end-to-end test with test
  accounts. The anonymous boundary and hosted authorization request are
  verified.
- Google federation is not enabled because this user pool has no Google
  identity provider. Email/password sign-in—including Gmail addresses—is live;
  adding a "Continue with Google" button requires a separately configured
  Google OAuth client and secret in Cognito.
- Desktop Chrome was visually inspected. Responsive CSS breakpoints were
  reviewed, but a true physical-device and cross-browser matrix is still a
  future automated test target.
- Research links support the learning mechanisms. They do not prove product
  outcome improvement; that requires a documented LearnByShorts study.
