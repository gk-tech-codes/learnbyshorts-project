Four-mission proof sprint

Do the work. Keep the evidence.

Check a mission only after the proof exists. Progress stays in this browser and also appears in the Modern Skills catalog.

  1. 01

    Build one vertical slice

    Implement one user outcome across UI, API, validation, storage, and error states.

    Proof: A working feature with typed boundaries.
  2. 02

    Test the risk

    Add unit, integration, and browser checks around the feature's highest-risk behavior.

    Proof: A test plan connected to real failure modes.
  3. 03

    Automate delivery

    Create a pipeline that checks formatting, tests, security basics, and build output.

    Proof: A green repeatable pipeline and a deliberately caught failure.
  4. 04

    Operate the release

    Add structured errors, health checks, rollback notes, and a lightweight cost estimate.

    Proof: An operational runbook for the deployed feature.
