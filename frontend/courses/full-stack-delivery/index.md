## Intended outcome

A tested full-stack application with a deployment pipeline and documented operational decisions.

## Why this path is current

Frameworks change; shipping a maintainable, testable product remains a durable engineering skill.

## Proof missions

### 1. Build one vertical slice

- Action: Implement one user outcome across UI, API, validation, storage, and error states.
- Evidence to produce: A working feature with typed boundaries.

### 2. Test the risk

- Action: Add unit, integration, and browser checks around the feature's highest-risk behavior.
- Evidence to produce: A test plan connected to real failure modes.

### 3. Automate delivery

- Action: Create a pipeline that checks formatting, tests, security basics, and build output.
- Evidence to produce: A green repeatable pipeline and a deliberately caught failure.

### 4. Operate the release

- Action: Add structured errors, health checks, rollback notes, and a lightweight cost estimate.
- Evidence to produce: An operational runbook for the deployed feature.
