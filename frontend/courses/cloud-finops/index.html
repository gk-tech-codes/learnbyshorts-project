Four-mission proof sprint

Do the work. Keep the evidence.

Check a mission only after the proof exists. Progress stays in this browser and also appears in the Modern Skills catalog.

  1. 01

    Choose the cheapest adequate shape

    Compare static, serverless, container, and managed options against traffic and reliability needs.

    Proof: An architecture decision record with estimated cost drivers.
  2. 02

    Make infrastructure repeatable

    Describe resources, permissions, encryption, and deletion safety as code.

    Proof: A reviewed change set with no public datastore.
  3. 03

    Observe the user outcome

    Define logs, metrics, alarms, and a trace from failure symptom to likely cause.

    Proof: A dashboard or runbook with alert thresholds.
  4. 04

    Install cost guardrails

    Set a budget, identify variable-cost events, and create a frugal degradation plan.

    Proof: A monthly cost envelope and shutdown checklist.
