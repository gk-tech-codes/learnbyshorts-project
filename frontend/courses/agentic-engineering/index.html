Four-mission proof sprint

Do the work. Keep the evidence.

Check a mission only after the proof exists. Progress stays in this browser and also appears in the Modern Skills catalog.

  1. 01

    Choose the right boundary

    Separate deterministic code, model judgment, tool calls, and human approval.

    Proof: A workflow diagram with stop and escalation conditions.
  2. 02

    Manage context deliberately

    Create compact instructions, task-specific memory, and a policy for what never enters context.

    Proof: A context budget and data-handling checklist.
  3. 03

    Connect one safe tool

    Define a narrow tool contract, validate inputs, and make retries idempotent.

    Proof: A tested tool schema with denied unsafe inputs.
  4. 04

    Evaluate the loop

    Build ten representative cases including failure, ambiguity, and adversarial input.

    Proof: An eval report with pass rate and one improved failure.
