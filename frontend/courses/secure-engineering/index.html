Four-mission proof sprint

Do the work. Keep the evidence.

Check a mission only after the proof exists. Progress stays in this browser and also appears in the Modern Skills catalog.

  1. 01

    Threat-model the outcome

    Map assets, actors, trust boundaries, abuse paths, and the impact of failure.

    Proof: A threat model with prioritized mitigations.
  2. 02

    Harden identity and data

    Verify authentication, authorization, session handling, storage exposure, and least privilege.

    Proof: A security checklist with anonymous-access tests.
  3. 03

    Secure the delivery chain

    Review dependencies, build permissions, secret handling, and release provenance.

    Proof: A dependency and pipeline risk report.
  4. 04

    Test AI abuse boundaries

    Probe prompt injection, data leakage, unsafe tool use, over-permission, and unsupported output.

    Proof: An adversarial test set and one repaired control.
