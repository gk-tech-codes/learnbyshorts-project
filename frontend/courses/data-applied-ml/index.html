Four-mission proof sprint

Do the work. Keep the evidence.

Check a mission only after the proof exists. Progress stays in this browser and also appears in the Modern Skills catalog.

  1. 01

    Start with the decision

    Write the decision, metric, grain, and minimum data required before opening a notebook.

    Proof: A one-page analysis contract.
  2. 02

    Interrogate the data

    Check missingness, duplicates, leakage, time boundaries, and surprising distributions.

    Proof: A data-quality report with one corrected defect.
  3. 03

    Beat a simple baseline

    Build the simplest credible query or model before adding complexity.

    Proof: Baseline results and a justified improvement.
  4. 04

    Explain the decision

    State the result, uncertainty, limitation, and recommended next action without model jargon.

    Proof: An executive summary plus reproducible code.
