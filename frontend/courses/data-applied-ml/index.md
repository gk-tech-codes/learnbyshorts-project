## Intended outcome

A reproducible analysis or model with data-quality checks and a decision-focused explanation.

## Why this path is current

AI increases the speed of analysis, but data quality and statistical judgment still determine whether it is useful.

## Proof missions

### 1. Start with the decision

- Action: Write the decision, metric, grain, and minimum data required before opening a notebook.
- Evidence to produce: A one-page analysis contract.

### 2. Interrogate the data

- Action: Check missingness, duplicates, leakage, time boundaries, and surprising distributions.
- Evidence to produce: A data-quality report with one corrected defect.

### 3. Beat a simple baseline

- Action: Build the simplest credible query or model before adding complexity.
- Evidence to produce: Baseline results and a justified improvement.

### 4. Explain the decision

- Action: State the result, uncertainty, limitation, and recommended next action without model jargon.
- Evidence to produce: An executive summary plus reproducible code.
