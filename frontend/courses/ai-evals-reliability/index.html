Four-mission proof sprint

Do the work. Keep the evidence.

Check a mission only after the proof exists. Progress stays in this browser and also appears in the Modern Skills catalog.

  1. 01

    Define observable success

    Write a narrow task contract with useful, harmful, abstaining, and ambiguous outcomes.

    Proof: A rubric with examples for every outcome class.
  2. 02

    Build the test distribution

    Create representative, edge, adversarial, and previously failed cases without leaking answers into the input.

    Proof: A versioned dataset of at least twenty labeled cases.
  3. 03

    Combine grading methods

    Use deterministic checks where possible, model graders where justified, and human review for disputed cases.

    Proof: A grader agreement report with known blind spots.
  4. 04

    Install a regression gate

    Compare two system versions on quality, safety, latency, and cost, then define the release threshold.

    Proof: A before-and-after scorecard that blocks one unacceptable regression.
